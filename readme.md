# MATLAB | Gaussian kernel model L2 constraint least squares learning method fitting + LSTM Long Short-Term Memory Neural Network | Included data and computational results | Direct to use

Article DOI: 10.1029/2022EA002660
Link: https://agupubs.onlinelibrary.wiley.com/doi/full/10.1029/2022EA002660
This article discusses a new method for remote sensing inversion of sea level, which involves applying the Gaussian kernel model L2 constraint least squares learning method to select values from numerous daily sea level inversions. At the same time, the Long Short-Term Memory (LSTM) neural network is used to predict based on sequential data, and the results are compared and analyzed with actual sea level measurements. Although the authors did not open-source the anti-noise estimation algorithm's code, their theoretical explanations were very clear and complete, allowing for a full reproduction.
